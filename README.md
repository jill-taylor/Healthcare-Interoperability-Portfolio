# Heartland Integrated Health System (HIHS)

## Legacy Infusion Pump Modernization Assessment

This repository documents a fictional healthcare technology discovery and current-state assessment developed as a professional portfolio project in healthcare interoperability and technical project management.

Heartland Integrated Health System (HIHS) and the project scenario are fictional. The methodologies, project artifacts, healthcare technology concepts, and technical approaches presented throughout this repository are based on real-world healthcare technology and project management practices.

---

## Project Focus

HIHS has identified a population of legacy infusion pumps that may present operational, cybersecurity, lifecycle, workflow, and interoperability considerations.

The project uses a structured discovery and current-state assessment process to understand:

- The device population
- Clinical workflows
- Information and communication flows
- Connectivity and integration dependencies
- Cybersecurity considerations
- Lifecycle and vendor-support conditions
- Stakeholder roles and dependencies
- Current-state risks and gaps
- Evidence and validation needs
- Decision-readiness considerations

The project does **not** select, design, procure, or implement a modernization solution.

The assessment establishes a documented current-state foundation to support responsible future planning and decision-making.

---

## Guiding Principle

**Discovery before solution.**

Successful healthcare technology projects require alignment among people, processes, clinical workflows, governance, cybersecurity, technology, and organizational decision-making.

This portfolio demonstrates how a Technical Project Manager can lead a focused healthcare technology discovery initiative by:

- Establishing the current state
- Organizing evidence and assessment activities
- Engaging stakeholders and subject matter experts
- Coordinating clinical and technical perspectives
- Identifying risks, gaps, and dependencies
- Maintaining evidence and validation boundaries
- Supporting decision-readiness
- Communicating findings for future planning

## Project Approach

The assessment follows a structured engagement lifecycle:

**Project Charter → Discovery Planning → Current-State Assessment → Stakeholder Analysis → Risk & Gap Assessment → Decision Readiness → Assessment Closeout**

### Current-State Assessment Sequence

The detailed current-state assessment follows:

**Environment → Device Inventory → Interface Inventory → Architecture → Clinical Workflow → Cybersecurity → Current-State Findings → Assessment-Level Stakeholder Analysis → Risk & Gap Assessment**

The assessment then transitions to:

**Decision Readiness → Assessment Closeout**

This progression demonstrates how a healthcare technology project can move from project definition and discovery through evidence collection, current-state analysis, risk and gap identification, decision-readiness evaluation, and formal closeout.

---

## Discovery Boundary

This project is intentionally limited to the **current-state discovery and decision-readiness phase**.

The project does **not** include:

- Future-state solution design
- Production implementation
- Production deployment
- Device configuration
- Production interface development
- Procurement
- Vendor selection
- Modernization roadmap development
- Production risk acceptance
- Post-project operational support

Future modernization planning may be considered in a subsequent phase using validated findings and evidence produced through discovery.
